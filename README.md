# 🇹🇷 Türkiye Yatırım Araçları — Çok Dönemli Performans Analizi

10 yıllık gerçek verilerle Türkiye'deki tüm yatırım araçlarının karşılaştırmalı analizi.

## 📊 Kapsam
- **Araçlar:** BIST100, Gram Altın, USD/TRY, EUR/TRY, S&P500, Bitcoin, Mevduat
- **Dönemler:** 1 Ay · 1 Yıl · 5 Yıl · 10 Yıl
- **Metrik:** Nominal getiri, Reel getiri (Fisher), Sharpe oranı, Volatilite

## 🔑 Temel Bulgular
- Gram Altın: 10 yılda **%356 reel getiri** — tek tutarlı enflasyon yenen TRY aracı
- Mevduat: Nominal %766 kazandırdı ama reel olarak **%32 eritti**
- BIST100: Uzun vadede güçlü ama kısa vadede oynak

## 🛠 Kullanılan Teknolojiler
`Python` `pandas` `numpy` `matplotlib` `seaborn` `yfinance`

## 🚀 Çalıştırmak İçin
```bash
pip install -r requirements.txt
jupyter notebook turkish_investment_analysis.ipynb
```
